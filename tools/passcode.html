Officer passcode

Firestore stores only the SHA-256 hash of your officer passcode, never the passcode itself. Generate the hash here, then save it in Firestore.

Hash to paste into Firestore
—
Where it goes. Firebase console → Firestore Database → Start collection:
  1. Collection ID: config
  2. Document ID: officer  (type it — don't use auto-ID)
  3. Field: codeHash  · type string · value = the hash above

Nobody can read that document from the app — the security rules block it outright. It's only ever compared against, server-side.

To rotate it later: generate a new hash here, overwrite codeHash, and delete the documents in the officerClaims collection to force everyone to re-enter it.

This page runs entirely in your browser and sends nothing anywhere. It needs https:// or localhost to work, because that's where the browser exposes its crypto library.
